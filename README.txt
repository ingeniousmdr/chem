# Chemistry Lab

## Files
- `index.html` — Home page
- `pt.html` — Interactive periodic table
- `chemcalc.html` — Chemistry calculator
- `style.css` — Shared stylesheet for every page
- `periodic.js` — Periodic table interactions
- `script.js` — ChemCalc calculations
- `site.js` — Shared responsive navigation behaviour

## Run
Keep all files in the same folder and open `index.html` in a browser.
For development, open this folder in VS Code and use Live Server.

All three HTML pages link to the same `style.css` and use the same navigation component.
